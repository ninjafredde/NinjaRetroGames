;   @thing NAME room=ROOM at=X,Y sprite=NAME   a person (16x16 sprite) standing on tiles X,Y (2x2 tiles)
;   @thing NAME room=ROOM at=X,Y size=WxH      something already drawn in the room, W x H tiles
; X,Y count tiles from the room's top left (0,0). People block John's path.
;
; What they say: each text line starts a new text box; a long line carries on in the next box.
; A box holds 2 lines of 18 letters. The font has capitals only (lowercase shows as capitals).
;
; Story state: names you make up (machine, asked...) are numbers that start at 0; items too (items.txt).
;   if machine=1 beans    the lines below are used when ALL of these hold:
;                         name=N  equals N,  name  is not 0,  !name  is 0,  name!=N  isn't N
;   do machine=2 give BEANS take FUSE shake rattle boom end
;                         happens when the box gets there: set a name, give/take an item,
;                         a small shake, a big rattle, the explosion, the end of the game
; The first "if" from the top that holds wins. Lines before the first "if" are used
; when no "if" holds.
